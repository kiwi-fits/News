# 🎥 Tamil AI News Reels Studio

Automated 24/7 AI-powered 9:16 vertical video reel generator for Tamil Breaking News and Evergreen stories (History, Science, General Knowledge, Wisdom Stories).

### Features:
- ⚡ **Real-Time News Monitoring**: Checks Sri Lankan Tamil feeds every 30 seconds.
- 🎙️ **Neural Voiceover**: Powered by Microsoft Edge-TTS (Valluvar male anchor voice at +12% speed).
- 🗣️ **English-to-Tamil Transliteration**: Automatically converts English words/terms into spoken Tamil phonetics.
- 🎞️ **9:16 Vertical Reels**: Rendered with FFmpeg, Ken Burns pan/zoom, channel logo branding, and ambient soundtrack.
- 🏛️ **30-Minute Evergreen Fallback**: Automatically creates educational reels if breaking news is quiet.
- 🚀 **Direct Facebook Reels Publishing**: Posts directly to Facebook Page with captions and hashtags.
